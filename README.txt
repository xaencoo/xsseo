Xsseo: готовый сайт

Файлы: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.
Сборка не нужна: это обычная статика.

Как выложить (любой вариант, всё бесплатно):
1. Netlify Drop: открой app.netlify.com/drop и перетащи эту папку.
2. Cloudflare Pages: Create project, Direct Upload, загрузи папку.
3. GitHub Pages: залей файлы в репозиторий, Settings, Pages, ветка main.

Нужен HTTPS (все три дают его сами). После выкладки сайт можно
установить как приложение: в Chrome пункт "Установить", в Safari
"Поделиться", затем "На экран Домой".
